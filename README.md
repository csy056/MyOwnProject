# 경계선 (가제)

> 달려라. 지도에서 지워지기 전에.

대한민국의 모든 시·군이 경계선을 따라 벽에 갇힌 지 412일. **내가 실제로 있는 동네**에서 시작하는 생존 텍스트 RPG이고, **실제로 달린 길**이 이야기 속 지도를 되찾는다.

- 전국 229개 시·군·구 어디서든 그곳이 무대가 된다. 해외에서 켜면 벽 바깥에서 들어온 외부인이 된다.
- 스토리 분기와 엔딩 일곱 개. 체력, 정신, 식량, 부품, 신뢰, 단서를 관리한다.
- 러닝 모드(선택): 달린 길의 블록(약 110m)을 되찾고, 고리를 닫으면 안쪽까지 되찾는다. 원정 보고, 무전 기록 열두 편, 공유 카드.
- 실제 밤낮과 연동되고, 새 동네에서 앱을 켜면 구역을 발견한다.
- 위치 좌표는 기기 밖으로 나가지 않는다.

## 바로 실행

```bash
npm install
npm start        # 휴대폰에 Expo Go를 설치하고 QR 스캔
npm run web      # 브라우저에서 실행
```

## 검증

```bash
npm run check    # 스토리 컴파일 + 자동 플레이 1500회 + 타입 검사 + 단위 테스트
```
