# 00. 컨셉 한 장과 냉정한 검토

## 한 장 요약

| 항목 | 내용 |
| --- | --- |
| 가제 | **경계선** (Borderline) |
| 태그라인 | 달려라. 지도에서 지워지기 전에. |
| 한 문장 | 대한민국의 모든 시·군이 경계선을 따라 벽에 갇힌 지 412일. 내가 실제로 있는 동네에서 시작하는 생존 텍스트 RPG이고, 실제로 달린 길이 이야기 속 지도를 되찾는다. |
| 타깃 | 1차: 20~30대 러너(러닝 크루, 기록 공유 습관). 2차: 텍스트·스토리 게임 팬(서울2033, 비주얼노벨 이용자) |
| 플랫폼 | Android, iOS (Expo). 웹 데모는 홍보용 |
| 수익 | 무료 + 보상형 광고(되감기, 보급 두 배) + 인앱 결제(광고 제거, 후원 팩). 2단계는 지역 이야기 확장팩, 러닝 시즌 |

### 핵심 경험 세 가지

1. **내 동네가 무대다.** 전국 229개 시·군·구 어디서 켜든 그곳이 거점이 된다. 해외에서 켜면 벽 바깥에서 들어온 외부인이 된다.
2. **달린 길이 이야기를 바꾼다.** 달린 블록을 되찾고, 고리를 닫으면 안쪽까지 한꺼번에 되찾는다. 보급, 단서, 무전 기록이 이야기로 돌아온다.
3. **짧고 무거운 선택.** 한 화면짜리 장면, 2~4개 선택지, 체력·정신·식량 관리, 엔딩 일곱 개.

## 냉정하게: 약점과 대응

| 약점 | 왜 위험한가 | 대응 |
| --- | --- | --- |
| 두 청중이 안 겹칠 수 있다 | 러너는 글을 안 읽고, 텍스트 게이머는 안 달릴 수 있다 | 각자 단독으로도 완결되게 했다. 텍스트 게이머는 러닝 없이 엔딩까지 볼 수 있다. 러너는 무전 기록, 되찾은 지도, 공유 카드만으로도 즐길 수 있다. 출시 후 지표로 어느 쪽이 붙는지 보고 무게를 옮긴다 |
| 텍스트 게임은 콘텐츠를 다 보면 끝난다 | 리텐션 절벽 | 러닝 무전(누적 기록 이정표), 구역 발견(여행 갈 때마다), 2주마다 지역 이야기 추가 |
| KYRO, INTVL이 이미 있다 | 땅따먹기로는 이길 수 없다 | 땅따먹기 경쟁(빼앗기, 랭킹)은 MVP에서 뺐다. 포지션은 "러너를 위한 이야기"다 |
| 위치정보법, 스토어 심사 | 출시가 막히거나 처벌받을 수 있다 | 좌표를 기기 밖으로 보내지 않는다. 만 14세 미만은 위치 기능을 끈다. 출시 전 신고 대상 여부를 확인한다 |
| 1인, 비개발자 | 유지보수 부담 | 스토리는 ink 텍스트라 코드 없이 쓴다. 자동 플레이 검사와 단위 테스트로 깨짐을 잡는다 |
| 바이럴 장치가 약하다 | 광고비 없이는 안 퍼진다 | 러닝 결과 공유 카드(문자 그림 지도), 고유 구역 이야기, 엔딩 공유. 2단계에 동네 랭킹 |
| 서울2033 아류로 보일 수 있다 | 평판 리스크 | 세계관(행정 경계 벽, 지도 AI), 위치 적응, 러닝으로 차별화. 지하철 중심 서사는 피했다 |

## 바이럴 고리

1. **러닝 공유 카드:** 러너는 이미 기록을 SNS에 올린다. 거리와 페이스 옆에 "벽 안에서 블록 46칸을 되찾았다"는 문구와 문자 그림 지도를 붙여, 평소 공유 습관에 그대로 올라탄다.
2. **"우리 동네가 게임에 나온다":** 종로, 마포, 영등포, 송파, 해운대, 유성에 고유 이야기가 있다. 지역 커뮤니티에서 공유할 거리다.
3. **수집:** 엔딩 일곱 개, 무전 열두 편, 구역 229개. 대화거리가 된다.
4. **(2단계) 동네 대항전:** 시·군·구 단위로 익명 집계한 "선꾼 지수"로 구 대항 랭킹을 만든다. 좌표는 보내지 않는다.

## 출시 순서

1. **클로즈드 베타 (2주):** 지인과 러닝 크루 2~3곳. 실제 기기로 GPS·배터리를 테스트하고 스토리 피드백을 받는다.
2. **소프트 런칭:** Google Play 먼저. 웹 데모 링크로 러닝·게임 커뮤니티에 알린다.
3. **정식 출시:** iOS 동시 출시. 위치기반서비스 신고 완료가 전제 조건이다.
4. **운영:** 2주마다 지역 이야기 한 곳씩 추가한다. 사용자가 많은 지역부터.

## 이번 MVP에서 일부러 뺀 것

서버, 계정, 친구·크루, 랭킹, 블록 빼앗기, 이미지 공유 카드, 실제 광고 SDK, 다국어. 모두 "출시 후 지표를 본 뒤" 결정한다.

### 총평

- 재미는 출시 가능한 수준이다. 세 명 모두 첫 5분의 훅(비어 있는 귀환 칸, 버클이 채워진 채 돌아온 시계)에 붙잡혔다.
- "걸음 = 측량값" 규칙이 8장에서 모눈의 공문 말투로 회수되는 구조가 스토리 점수 8~9를 만들었다.

### 강점

1. 강한 오프닝과 메타 반전
2. 원정 보고 이정표처럼 달리기가 세계관의 단서로 바뀌는 순간
3. 지역 고유 장면 (석촌호수, 광화문 도로원표, 한강의 회색 러너 무리)

### 위험과 대응
