# 02. 러닝 모드 (플러스 알파)

> 상태: 설계 확정, MVP 구현 완료 (2026-10-17)

## 결론부터

- 러닝은 **"달려야 지도에 남는다"**는 세계관 규칙 자체다. 그래서 덧붙인 기능이 아니라 이야기의 일부가 된다.
- **땅따먹기 앱과 정면 승부하지 않는다.** 국내에 이미 강자(KYRO)가 있다. 우리는 "달리기에 이야기를 입히는 앱"이고, 땅따먹기는 그 이야기의 손맛이다.
- **MVP는 서버 없이 기기 안에서 끝낸다.** 경로 좌표는 러닝이 끝나면 지우고 약 110m 블록 ID만 남긴다. 다른 사람과 땅을 빼앗고 뺏기는 기능은 법률 검토와 서버 준비가 끝난 2단계에서 한다.
- **러닝은 선택이다.** 달리지 않아도 메인 스토리는 끝까지 볼 수 있다.

## 레퍼런스: "일본에서 유행한 러닝 땅따먹기"의 정체

사용자가 말한 사례는 **KYRO**(일본 스토어 이름 "KYRO: ランニング陣取りゲーム")로 보인다. **KYRO는 일본 앱이 아니라 서울 마포구 스타트업(무브먼트랩)이 만든 한국 앱**이다. 2026년 1월에 출시됐고, 같은 해 4~7월 일본에서 역으로 크게 유행했다.

| 항목 | KYRO | INTVL (원조) | ZRX (구 Zombies, Run!) |
| --- | --- | --- | --- |
| 국가, 출시 | 한국, 2026.1 | 호주 멜버른, 2024 | 영국, 2012 |
| 핵심 | 달린 경로로 고리를 그리면 안쪽 면적이 내 영토. 남이 둘러싸면 빼앗김 | 같은 고리 방식 (KYRO가 모방했다는 비판, 창업자 일부 인정) | 달리는 동안 오디오로 좀비 생존 스토리 |
| 규모 | 가입 8만+, MAU 약 4만 (2026.5 자체 발표). 일본 3만+ (닛케이MJ 2026.7) | 250만+ 다운로드, 182개국 (2026.7) | 장수 앱, 구독 모델 |
| 수익 | PRO 구독 (월 11,900원), 브랜드 스폰서 챌린지 | Pro 구독 | 부분 무료 + 구독 |
| 지적된 문제 | GPS 오차(빌딩숲·고가), 배터리, 집 위치 노출, 서버 불안정, 영토 욕심에 인도 없는 길·야간·100km 무리 | 느린 러너에게 쉽게 빼앗김, 방어 수단 없음 | - |

그 밖의 선례: Run An Empire(영국, 2016, 육각형 칸, 가속도계로 부정행위 탐지), Ingress(포털 3개로 삼각형 영역), 그라운드 플립(한국, 걸어서 픽셀 점령), 信長の野望 出陣(코에이테크모, 2023, 걸어서 영지 확장).

### 가져올 것과 피할 것

| 가져올 것 | 피할 것 |
| --- | --- |
| 고리를 닫으면 안쪽을 한꺼번에 얻는 손맛 (KYRO, INTVL) | 정밀 경로를 서버에 올려 남에게 보여 주는 구조 (위치 노출, 법적 부담, 서버 비용) |
| 달리는 동안은 화면 대신 소리로 전달 (ZRX) | 결제로 영토를 지키는 페이투윈 (Territory Run이 비판받음) |
| 부정행위 기준 공개 (KYRO는 비공개로 불신을 삼) | 넓이 경쟁이 무리한 루트를 부르는 구조 → 하루 보상 상한 |
| 크루, 지역 랭킹 (2단계) | 밤에 나가면 보상이 커지는 설계 (L4 밤은 이야기에만 영향) |

## 핵심 컨셉

> 사람이 다니지 않는 곳은 지도에서 지워진다. 그러니 달려라.

- 세계관에서 벽은 지도 정합 AI "모눈"이 만든 것이다. 모눈은 사람의 이동을 "측량값"으로 읽고, 측량값이 없는 곳을 회색으로 지운다.
- 생존자들은 매일 길을 걷고 달려서 선을 긋는다. 이 사람들이 **선꾼**이다.
- 플레이어가 실제로 달리면 선꾼이 된다. 달린 블록은 게임 속 지도에서 색을 되찾고, 그 보급과 기록이 이야기로 돌아온다.

## 러닝 모드 흐름

| 단계 | 화면 | 내용 |
| --- | --- | --- |
| 출발 전 | 원정 준비 | 안전 수칙(이어폰 볼륨, 차도·사유지·출입 금지 구역 금지, 밤이면 밝은 옷과 밝은 길), 오늘 보급 횟수 |
| 달리는 중 | 큰 숫자 화면 | 거리·시간·페이스·새 블록. **화면을 보지 않아도 된다.** 1km마다 음성 안내, 고리를 닫으면 음성과 진동 |
| 끝난 뒤 | 원정 보고 | 거리, 시간, 페이스, 새 블록, 포위 횟수, 문자 그림 지도, 보급, 새 무전, 공유 |
| 이야기 | 거점 허브 | "원정 보고를 한다" 선택지가 생긴다. 강도윤이 페이스와 거리를 두고 코치처럼 반응한다. 이정표마다 단서를 준다 |

화면에 뜨는 문구 예:

```
3km. 블록 27칸 탈환. 발밑의 색이 돌아온다. 계속.
포위 성공. 고리 안쪽 41칸이 색을 되찾는다. (새로 38칸)
```

## 땅따먹기 설계 (구역 탈환)

| 항목 | 규칙 |
| --- | --- |
| 블록 | 위도 0.001° × 경도 0.00125° ≈ 110m × 110m. 전국 어디서나 동작 |
| 밟기 | 달린 선이 지나간 블록을 되찾는다 (20m 간격 보간) |
| 포위 | 300m 이상 달린 뒤 예전 지점 35m 안으로 돌아오면 고리가 닫힌다. 안쪽 블록 4칸 이상이면 한꺼번에 되찾는다 (한 고리 최대 600칸) |
| 저장 | 블록 ID만 기기에 저장. 원래 경로 좌표는 러닝이 끝나면 버린다 |
| 지도 표시 | 실제 지도 타일 없이 "측량 도면"처럼 격자만 그린다. 주소와 지명은 표시하지 않는다 |

KYRO·INTVL의 자유 다각형 방식과 달리 **격자 블록**을 쓴다. 이유는 세 가지다.

1. 세계관의 "모눈(격자)"과 맞는다.
2. 좌표 대신 블록 ID만 남겨 개인정보 노출이 줄어든다.
3. 2단계에서 서버와 공유할 때도 거친 단위로만 주고받을 수 있다.

## 스토리와의 연결

| 연결 지점 | 내용 |
| --- | --- |
| 원정 보고 | 러닝 뒤 거점에서 강도윤과 한서진이 반응한다. 거리 구간(2km 미만, 2~5, 5~10, 10 이상), 페이스, 포위 여부에 따라 대사가 달라진다. 짧고 느린 러닝도 반드시 칭찬한다 |
| 단서 | 첫 포위, 원정 3회, 누적 10km에 한 번씩 선택 단서를 준다. 진실 엔딩에 필요한 단서를 더 빨리 모을 수 있다 (러닝 없이도 탐색으로 모을 수 있다) |
| 보급 | 식량 1~3, 부품 0~3. 하루 2회까지만 준다 |
| 2장 | 러닝을 해 본 플레이어에게는 "지난번 원정"을 언급한다 |
| 무전 기록 | 누적 기록(원정 횟수, km, 포위, 블록)이 쌓이면 다른 벽의 선꾼들이 보낸 무전 12편이 열린다. 하프(21.1km), 풀코스(42.195km) 이정표도 있다 |

## 달리지 않는 플레이어를 위한 경로

- 메인 스토리, 엔딩 다섯 개 모두 러닝 없이 볼 수 있다.
- 단서는 탐색, 거점 대화, 장 진행으로도 충분히 모인다.
- 걷기도 기록된다. 속도 하한은 없다.
- 만 14세 미만이거나 위치에 동의하지 않으면 러닝 메뉴에 이유를 설명하고 끈다.

## 위치정보, 스토어 정책, 안전, 치트 대응

### 위치정보 처리

| 데이터 | 처리 | 저장 위치 |
| --- | --- | --- |
| 현재 위치 (시작, 구역 발견) | 기기 안에서 시·군·구 이름으로 바꾸고 좌표는 버린다 | 구역 이름만 기기 |
| 러닝 경로 | 러닝 중 메모리(백그라운드일 때는 기기 임시 버퍼)에만 둔다. 끝나면 블록 ID로 바꾸고 지운다 | 블록 ID만 기기 |
| 서버 전송 | 없음 | - |

**확인 필요:** 서버로 위치를 보내지 않아도 위치기반서비스사업 신고 대상인지는 법령 원문과 방송미디어통신위원회 해석으로 확인해야 한다. 신고 의무가 있으면, 미신고 운영 시 형사처벌 조항이 있다. 출시 전에 KISA 위치정보지원센터 상담을 받고, 대상이면 신고한다. 2단계(서버 공유)는 개인위치정보 수집이 되므로 별도로 검토한다.

### 스토어 정책

- **"항상 허용" 위치 권한을 요청하지 않는다.** 러닝을 시작할 때 "앱 사용 중" 권한만 쓴다.
- **Android:** 알림이 뜨는 포그라운드 서비스로 화면이 꺼져도 기록한다. `ACCESS_BACKGROUND_LOCATION`을 매니페스트에서 뺐으므로 Play의 백그라운드 위치 선언서와 시연 영상이 필요 없다. 포그라운드 서비스 유형(location)은 Play Console에서 신고한다. Android 13 이상은 서비스 알림을 위해 알림 권한을 묻는다(거부해도 기록은 된다).
- **iOS:** 위치 표시줄(파란 표시)을 띄운 채 기록한다(UIBackgroundModes location). 심사에서 "러닝 기록이 핵심 기능"임을 설명한다.
- **Expo Go와 웹:** 백그라운드 기록이 지원되지 않아 화면을 켜 두는 모드로 동작한다. 실제 기기 테스트는 개발 빌드(EAS)에서 한다.

### 안전

- 달리는 동안 읽을 글이 없다. 음성과 진동으로만 알린다.
- 출발 화면에 차도, 사유지, 출입 금지 구역(군사시설 등) 금지 안내를 띄운다. 밤이면 밝은 옷, 밝은 길 안내를 추가한다.
- 밤에 달려도 보상이 커지지 않는다. L4 밤낮 연동은 이야기 이벤트에만 영향을 준다.
- 보상 하루 상한(2회)을 둬서 무리한 장거리와 연속 러닝을 유도하지 않는다.
- 만 14세 미만은 러닝 모드를 끈다. 법정대리인 동의 절차는 2단계에서 검토한다.

### 치트 대응 (기준 공개)

| 규칙 | 값 |
| --- | --- |
| 정확도가 나쁜 위치 버림 | 35m 초과 |
| 차량 속도 구간 버림 | 7m/s(25.2km/h) 초과. 4번 연속이면 "차량 의심" 안내 |
| 가짜 위치(모의 위치) 버림 | `mocked` 플래그 |
| 신호 끊김 | 60초 이상 끊기거나 400m 이상 튀면 그 구간은 세지 않는다 |
| 최소 거리 | 300m 미만은 원정으로 치지 않는다 |

2단계에서 만보계(가속도계) 교차 검증을 추가한다.

## 단계별 범위

| 단계 | 내용 | 상태 |
| --- | --- | --- |
| MVP | 기기 안 러닝 기록, 블록 탈환, 포위, 음성 안내, 원정 보고 스토리, 무전 12편, 이미지 공유 카드(도윤의 한마디), 하루 보상 상한, 광고 보고 보급 두 배 | 구현 완료 |
| 1.1 (베타 전 권장) | **다른 앱 기록 가져오기:** Health Connect의 운동 경로(Android), HealthKit 운동 경로(iOS), GPX 파일. 가져온 경로도 같은 치트 필터와 하루 상한을 거쳐 블록으로 바꾸고 좌표는 버린다. 이미 Strava·NRC로 뛰는 크루 러너가 앱을 두 개 켜지 않게 한다 | 설계 (네이티브 모듈이라 개발 빌드에서 검증 필요) |
| 1.1 (베타 전 권장) | **실제 날짜로 장 열기:** 4장부터는 "다음 날이 되거나, 오늘 원정(300m 이상)을 다녀오면" 다음 장이 열린다. 매일 저녁 알림(끌 수 있음). 돌아올 이유와 러닝의 무게를 함께 키운다 | 설계 (밸런스 재조정 필요) |
| 2단계 | 시·군·구 단위 "선꾼 지수"를 익명으로 집계해 동네 랭킹 (좌표 없이 구역 ID + 거리 합계만 전송), 주간 스트릭, 만보계 교차 검증 | 설계 |
| 3단계 | 크루(거점 단위 팀), 블록 쟁탈(빼앗기·지키기), 시즌 이벤트 | 법률 검토 후 |

## 수익화 연결

- **보상형 광고:** 원정 보급 두 배 (하루 1회)
- **보상형 광고:** 사망·회색 엔딩에서 마지막 선택 직전으로 되감기
- **인앱 결제:** 광고 제거 (₩3,900), 후원자 팩 (₩9,900)
- **2단계:** 러닝 스토리 시즌 패스, 지역 이야기 확장팩. 스폰서 챌린지는 KYRO 사례 참고
- **하지 않는 것:** 건강·위치 데이터를 광고 타기팅에 쓰지 않는다. 결제로 블록을 지키게 하지 않는다

## 리스크와 확인할 것

- **경쟁:** KYRO와 INTVL이 땅따먹기 시장을 잡고 있다. 땅따먹기 단독 경쟁은 피하고, 스토리 경험으로 승부한다.
- **위치정보법 신고 대상 여부:** 확인 필요 (출시 전 필수).
- **Play 포그라운드 서비스 심사:** 위치 유형 포그라운드 서비스 신고가 필요하다. 백그라운드 위치 권한은 쓰지 않는다.
- **러너의 진입 장벽:** 이미 다른 러닝 앱을 쓰는 사람에게 앱을 하나 더 켜라는 요구는 크다. 1.1의 기록 가져오기가 가장 중요한 다음 작업이다 (플레이테스트에서 러닝 적합도 4~7점).
- **GPS 오차:** 빌딩숲과 고가 아래에서 정확도 필터 때문에 블록이 덜 잡힐 수 있다. 실제 기기 테스트가 필요하다.
- **배터리:** 정확도 최고 설정, 5m 간격 수집. 실측 후 조정한다.
