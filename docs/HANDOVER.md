## 이어받는 방법

1. `npm install`
2. 읽는 순서: 이 문서 → `docs/00` → `04` → `05` → `03`
3. `npm run check`로 현재 상태를 확인한다 (스토리 컴파일, 자동 플레이, 타입 검사, 단위 테스트).
4. 스토리 파일에 "작성 예정"이 남아 있으면 `docs/05-story-guide.md` 규칙대로 채운다. `npm run story:test`의 "미완성 문구" 목록이 남은 일이다.

## 알려진 문제

- Expo Go와 웹에서는 백그라운드 위치가 지원되지 않아 러닝 중 화면을 켜 둬야 한다. 개발 빌드에서는 화면을 꺼도 기록된다.
- 인천 개편 구역(제물포구·영종구·검단구)은 경계를 근사했다.
- 광고·결제는 시뮬레이션이다.
