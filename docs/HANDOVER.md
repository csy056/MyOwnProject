## 이어받는 방법

1. `npm install`
2. 읽는 순서: 이 문서 → `docs/00` → `04` → `05` → `03`
3. `npm run check`로 현재 상태를 확인한다 (스토리 컴파일, 자동 플레이, 타입 검사, 단위 테스트).
4. 스토리 파일에 "작성 예정"이 남아 있으면 `docs/05-story-guide.md` 규칙대로 채운다. `npm run story:test`의 "미완성 문구" 목록이 남은 일이다.
5. 스토리가 다 채워지면 `node scripts/playtest.mjs 3000`으로 엔딩 분포를 보고 밸런스를 맞춘다. 목표: 사망·회색 25~50%, 탈출·잔류 35~65%, 진실 엔딩 5~25%.

## 알려진 문제

- Expo Go와 웹에서는 화면을 꺼 두면 러닝이 기록되지 않는다. 개발 빌드에서는 알림(Android)이나 위치 표시줄(iOS)을 띄운 채 화면을 꺼도 기록된다.
- 인천 개편 구역(제물포구·영종구·검단구)은 경계를 근사했다.
- 광고·결제는 시뮬레이션이다.
