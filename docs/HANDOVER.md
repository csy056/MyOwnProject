## 이어받는 방법

1. `npm install`
2. 읽는 순서: 이 문서 → `docs/00` → `04` → `02` → `03` → `05`
3. `npm run check`로 상태를 확인한다.
4. 스토리를 고친 뒤에는 `node scripts/playtest.mjs 3000`으로 엔딩 분포를 확인한다. 직접 플레이는 `node scripts/play-cli.mjs` (README 참고).

## 알려진 문제

- Expo Go와 웹에서는 화면을 꺼 두면 러닝이 기록되지 않는다. 개발 빌드에서는 화면을 꺼도 기록된다.
- 인천 개편 구역(제물포구·영종구·검단구)은 경계를 근사했다.
- 광고·결제는 시뮬레이션이다.
- 자동 플레이 봇은 무작위로 고르므로 실제 사람보다 훨씬 자주 죽는다. 사람 기준 난이도는 페르소나 플레이테스트 결과를 함께 본다.
